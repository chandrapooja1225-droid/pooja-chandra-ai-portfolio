Featured Project

Multi-Class Mental Health Detection Using Transformer-Based NLP

An MSc research project exploring whether domain-adapted transformer models can improve seven-class mental-health text classification, while making model behaviour more interpretable and comparing fine-tuned models with a general-purpose LLM.

How I Built It

Engineering the experiment

01 · Data investigation

Three public licensed datasets were reviewed and combined. A cross-dataset text-overlap investigation found 39,469 exact-text duplicates in Dataset 3 that were already represented in Dataset 1 or Dataset 2. Removing these produced the final 147,139-sample corpus.

02 · Baseline modelling

TF-IDF was used to represent text for classical machine-learning baselines. Logistic Regression and Linear SVM established reference performance before moving to domain-specific transformer models.

03 · Transformer fine-tuning

MentalBERT and MentalRoBERTa were fine-tuned with Hugging Face Transformers for the seven-class classification task, allowing the experiment to test domain adaptation rather than relying only on general-purpose language representations.

04 · Evaluation

Accuracy, Precision, Recall and Macro F1 were used alongside confusion matrices. McNemar's test was applied to compare model predictions and assess whether differences between approaches were statistically significant.

05 · Explainability

SHAP PartitionExplainer was used to inspect the vocabulary contributing to predictions. The analysis helped investigate difficult boundaries between related categories and exposed a self-labelling artefact in the Bipolar Disorder category.

06 · LLM benchmark

Llama 3.3 70B was evaluated through zero-shot and few-shot prompting on a shared 210-sample subset, creating a controlled comparison between prompting and domain-specific fine-tuning.

A key engineering lesson

The experiment did not assume that a larger general-purpose LLM would automatically outperform a domain-specific model. The measured results provided evidence for the role of domain-specific fine-tuning on this particular classification task.

Problem Solving

The interesting part was not only the final score

Finding hidden data overlap

Post-hoc validation revealed substantial exact-text overlap across the source datasets. Investigating and removing those records became an important part of producing a more rigorous modelling corpus.

Understanding model behaviour

SHAP analysis went beyond reporting a score by examining the vocabulary influencing predictions, including difficult distinctions between related categories.

Testing the LLM assumption

A general-purpose LLM was benchmarked under two prompting strategies rather than being treated as a replacement for fine-tuned models without measurement.

Reporting limitations honestly

The study documents limitations including self-assigned labels without clinician verification, the small SHAP audit sample, and the use of one LLM provider/model configuration.

Responsible AI

Interpretability, limitations and human oversight

The project treats the model as a research decision-support system, not as an autonomous diagnostic tool. This distinction shaped how the results and limitations were interpreted.

Data quality

Self-labelled social-media data can contain label noise and was not clinically verified.

Explainability

SHAP was used to expose influential vocabulary and investigate potential model artefacts.

Human review

Potentially important model outputs should support human assessment rather than make clinical decisions automatically.
